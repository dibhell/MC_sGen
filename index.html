📖 Jak wgrać wygenerowaną skórkę do Minecrafta?

Minecraft Java Edition (PC / Mac)

  1. Kliknij przycisk Pobierz Skin i zapisz plik skin.png.
  2. Uruchom Minecraft Launcher.
  3. Wybierz zakładkę Skins (Skórki) na górnym pasku.
  4. Kliknij New Skin (Nowa skórka).
  5. Wybierz model Classic (lub Slim) i kliknij Browse, wybierając pobrany plik.
  6. Kliknij Save & Use – gotowe!

Minecraft Bedrock Edition (Windows / Konsole / Mobile)

  1. W menu głównym gry kliknij Garderoba (Dressing Room).
  2. Wybierz ikonę Klasyczne skórki (zielony wieszak).
  3. Kliknij Posiadane skórki → Wybierz nową skórkę.
  4. Wskaż pobrany plik skin.png ze swojego dysku / galerii.
  5. Wybierz model ramion i zatwierdź!
