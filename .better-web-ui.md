# Project Design Context (.better-web-ui.md)

## Design Context

### Users
Minecraft players of all ages, skin customizers, content creators, and server admins looking for an effortless, instant way to turn their real-life photo or avatar into an authentic, ready-to-play Minecraft skin without complex manual pixel editors.

### Brand Personality
- **Voice & Tone**: Confident, technically capable, playful yet professional.
- **3-Word Personality**: Tactile, Precise, Futuristic-Retro.
- **Emotional Goals**: Delight from seeing oneself instantly voxelized; confidence that the skin file will work flawlessly in Minecraft Launcher without black box or alpha clipping bugs.

### Aesthetic Direction
- **Visual Tone**: Dark Luxury Voxel (Deep obsidian black `#090a0f`, slate surfaces, emerald green `#10b981` accents, cyan highlights `#06b6d4`, crisp 3D voxel beveled controls).
- **References**: Authentic Minecraft Java GUI, Modern Bento Grid dashboards, Three.js/WebGL interactive showcases.
- **Anti-references**: Cluttered generic AI gradients (pink/purple mush), flat unstyled HTML forms, unreadable low-contrast dark themes.
- **Theme**: Dark Mode by default with authentic Minecraft stone/wood/emerald/diamond motifs.

### Implementation Defaults
- **Framework**: React 18 (Vite SPA)
- **Styling System**: Tailwind CSS v3 + Custom CSS classes (`.mc-panel-3d`, `.mc-button-3d`, `.mc-slot`)
- **Animation**: Framer Motion
- **Iconography**: Lucide Icons
- **3D & Graphics**: `skinview3d` (Three.js), `vgpu` (WebGPU WGSL shader atmosphere), HTML5 Canvas 2D
- **Color Semantics**:
  - `brand-primary` / `action-primary`: Emerald `#10b981`
  - `accent-technical`: Cyan `#06b6d4` / `#55FFFF`
  - `status-warning`: Amber `#f59e0b`
  - `surface-base`: `#090a0f`
  - `surface-card`: `#12151f` (with subtle border and backdrop blur)
  - `surface-inset`: `#0d0f17` (slot style)

### Design Principles
1. **Guide the Journey in 3 Clear Steps**: Hero/Status -> Upload -> Customize -> 3D Preview & Download.
2. **Tactile Minecraft Physics**: Interactive buttons should feel pressable with physical bevels and active state depression.
3. **Restrained, Meaningful Color**: Use emerald for success/primary CTA, cyan for technical/AI indicators, amber for attention. Avoid rainbow scatter.
4. **Resilience Across Devices**: Ensure layout adapts gracefully from mobile phones (375px) to ultra-wide displays (1440px+).
5. **Accessibility by Default**: Minimum 4.5:1 text contrast, visible focus rings, aria labels on icon-only buttons, respecting prefers-reduced-motion.
